# 할당 취소된 VM도 vCPU 할당량을 차지한다

- 날짜: 2026-11-23

## 문제

VM 크기를 바꾸려는데 같은 계열(Bsv2) 안의 크기 변경도 할당량 때문에 막혔다.

## 원인

- 할당 취소(중지)된 VM도 지역 vCPU 할당량을 차지한다. VM 두 대가 모두 중지 상태일 때 Bsv2 사용량이 4로 나왔다.
- 종량제로 전환한 뒤 확인해 보니 Bsv2 한도가 0이라 사용량이 한도보다 많은 상태였다. 이때는 같은 계열 안의 크기 변경도 막혔다.

## 해결

- Bsv2 한도 4를 신청해 승인받은 뒤에 크기가 바뀌었다.
- Basv2는 자동 한도 신청이 거절됐다. 이 경우는 지원 티켓(무료)으로 요청해야 한다. (안 해 봄)

## 배운 점

- 중지만으로는 할당량이 비지 않는다. 사용량은 중지된 VM까지 포함해서 본다.
- 한도가 사용량을 덮은 뒤에는 vCPU 수가 같은 크기로 바꿀 때 추가 신청이 필요 없다. (추론)
